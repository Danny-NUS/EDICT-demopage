Abstract

Instruction-based text-to-speech requires control over both who speaks and how each segment is delivered. EDICT connects a trainable, reference-conditioned timbre editor with a frozen autoregressive TTS backbone. The editor maps a source voice and attribute operations to an edited codec reference, which remains a shared voice anchor across successive segments. At instruction boundaries, EDICT reconstructs the key–value cache under the new conditions, using retained initial and recent acoustic inputs to support speaker consistency and continuity.

The two modules compose without joint training; local control requires no additional backbone training. Experiments on TimbreEdit-Bench and IntraTTS-Bench evaluate the two controls separately and together. Results show improved edit accuracy and local instruction control, alongside trade-offs in attribute preservation and content fidelity.

Method overview

A trainable timbre editor and a frozen TTS backbone compose through a shared edited reference.

01

Interpret the edit

Map a natural-language request to operations on nine perceptual voice attributes. Unmentioned attributes receive a keep operation.

02

Create a voice anchor

The trained editor produces an edited codec reference, reused across all segments of the subsequent synthesis.

03

Refresh the context

At each instruction switch, reconstruct the KV cache using the new instruction, shared reference, and initial and recent acoustic context.

What changes at an instruction boundary?Explore the KV cache ↗

Cached acoustic states can carry conditioning from an earlier instruction. EDICT discards the old cache and recomputes selected acoustic inputs under the new conditions. Initial context supplies evidence of the established voice; recent context supplies continuation cues. The generated segments remain in one codec stream.

The local control stage requires no additional backbone training.
