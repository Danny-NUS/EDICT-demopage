# EDICT Demo Page

Anonymous demos for global timbre editing and local instruction control in text-to-speech.

- **Overview:** Introduces how EDICT edits voice characteristics and controls expression across text segments.
- **Joint Control Demos:** Six English and Chinese examples with a shared voice reference and changing expression. Waveform colors match the instructions, and clicking a segment starts playback from that point.
- **Timbre Editing:** Four examples comparing EDICT with baseline systems under the same voice-editing request.
- **Local Instruction Control:** Four examples comparing segment-level instruction following, voice consistency, and transitions.
- **Results:** Interactive mean opinion score charts and the main experimental comparisons for timbre editing, local control, and joint control.
- **Abstract:** Summarizes the motivation, approach, and main findings.
- **Method Overview:** Explains the timbre editor, shared voice reference, and KV cache reconstruction.
